# Design Brief

## Direction
Quiet editorial layout: warm off-white canvas, charcoal type, muted forest-green accents, ample whitespace, and italic serif highlights. White-first theme with a complete charcoal/green dark theme. System Arial and Georgia avoid network font dependencies.

## Composition
Compact navigation; bold value-led hero with an illustrative workflow; concise technology strip; four project covers; three approach principles; short biography; direct contact invitation; minimal footer. Project covers use the supplied LedgerLens overview, Northstar Workflow Demo, Niven invitation, and DTSS reports capture. LedgerLens, Northstar, and Niven galleries use supplied screen captures. Niven's gallery includes all eight captures, with visible names and event details, per owner request. DTSS gallery uses the owner-supplied images unchanged.

## Interaction and accessibility
Animated connector dots, soft emphasis, subtle hover elevation, and one-time scroll reveals. Honor prefers-reduced-motion. Use semantic headings, visible keyboard focus, skip navigation, descriptive button labels, native modal dialog, and persistent theme preference. Project detail dialogs explain scope and demo limitations.

## Responsive behavior
Two-column hero/work grid on wide screens; single-column layout below 700px. Navigation remains visible on mobile. Fluid headlines, wrapping tool labels, and compact footer prevent crowding. Project detail galleries use responsive image previews. Inspect both themes at desktop and narrow widths before publication.
