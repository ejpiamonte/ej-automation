# EJ Piamonte — Automation Portfolio

A dependency-free, responsive portfolio with a light-first theme, persistent dark mode, subtle workflow animation, scroll reveals, and accessible project-detail dialogs.

Run `npm run dev` and open http://127.0.0.1:4173. Run `npm run check` for the browser script syntax check. The deployable static files are in `dist/`; no compilation, API credentials, or database are needed. The included server binds only to loopback and is for local preview.
